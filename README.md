# Mario Mach

Minimal personal portfolio built with Next.js and Tailwind CSS.

## Development

Use Node.js 22 or newer, then run `npm install` and `npm run dev`.

Run `npm run build` to verify the production build.

Vercel deploys the main branch to mariomach.com. The portrait is in `public/portrait.jpg`; page content and contact links are in `app/page.jsx`.
